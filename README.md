## Projects

### [1. Number Analyzer]
- Collects and validates numerical input from users
- Performs statistical analysis (average, min, max, sum)
- Categorizes results with clear output formatting
- Implements professional error handling and user feedback

### [2. Role Management System]
- Manages employee roles with three-tier hierarchy (Admin, User, Guest)
- Displays sorted roster with said hierarchical ordering
- Uses a state machine with boolean state control
- Enforces business rules including guest limits (max 3) and input validation
- Utilizes parallel collections (List<string>) for data management
- Features professional error handling and cleans user input

### [3. MyPetDaycare]
- Virtual pet game with feeding, play, and rest mechanics. Balancing these aspects of your pet is crucial to avoid a Game Over.
- Messed around a bit with ASCII art to make the console program experience a bit more enjoyable
- Uses a simple Save/Load system using file I/O so you can create and take care of as many pets as you want.
- The pet reacts to you based on what you do with it and how it is feeling at a given time considering its hunger, energy, and happiness.
- Tried to implement OOP principles and built the program with future scalability in mind. For example, StringBuilder to save on memory usage and arrays to make adding new functions easy without messing with other parts of the program.
